# 동의 스냅샷의 외부 hook 간섭 수정

기준일: 2026-10-06. 수정 전 기준 커밋: `202f8ba`. 현재 동작은 [사용 가이드](../usage.md#내부-처리), [설계](../design.md), [설치](../install.md)를 따른다.

## 원인과 확인

Git 파일 목록을 읽은 뒤 루트 전체를 다시 순회해 무시된 외부 세션·캐시까지 동의 해시에 포함했다. 기존 도입·반영·도메인 수정과 `consent finish` 추가로는 해결되지 않았다. 수정 전 재현에서는 POLICY 4종과 Git status가 같은 상태에서 무시된 `aidlc/.aidlc-sessions/usage-ledger.json`만 바꿔도 질문 전과 응답 기록 시점은 pending으로 차단됐고, 승인 후 적용 전은 approved 상태에서 적용이 차단됐다. `.gradle/`·`logs/`의 파일 변경도 해시를 바꿨다.

## 수정된 계약

| 대상 | 처리 |
|---|---|
| Git 일반 저장소·worktree | 추적 파일과 무시되지 않은 새 파일을 기본 대상으로 삼고 루트 전체를 걷지 않는다. |
| Git이 없는 디렉토리 | 기존 루트 순회와 캐시 이름 제외 규칙을 유지한다. |
| 무시된 필수 설정·문서 | `code-agent.json`·`CLAUDE.md`·`AGENTS.md`, `.code-agent`(consents 제외)·`.claude`·`.agents`·`.codex`·`doc`·`docs`, 등록된 POLICY·KNOWLEDGE·단계 템플릿·spec는 계속 해시한다. |
| 준비 커밋 | setup/baseline이 실제로 커밋할 경로도 해시한다. 무시된 README 등도 질문 후 바뀌면 차단한다. |
| 변경 진단 | 파일별/상태별 해시를 기록해 추가·삭제·수정 경로와 Git HEAD·브랜치·index·설정 등을 최대 6개와 나머지 개수로 안내한다. 파일 본문·Git 설정 원문을 추가 저장하지 않는다. |
| 이전 동의 기록 | 전체 해시 검증은 유지한다. 불일치 시 상세 해시가 없음을 알리고 재준비를 안내한다. |
| 도움말 | 접수·문서 작성·작업 중 `code-agent help`·`code-agent --help`를 허용한다. 명령 연결·리다이렉트와 임의 추가 인자는 열지 않는다. |

명시 범위 밖의 무시된 `.env`·`gradle.properties` 같은 실행 설정은 이 동의 스냅샷에서 빠진다. 반대로 명시 범위 안의 로그와 Git 추적 중인 감사 파일은 변경 시 계속 차단한다. 임의 `consent.include/exclude` 설정이나 외부 hook 제거는 도입하지 않았다. 다른 도구의 기록이 추적 파일을 바꾸는 상황까지 자동 허용하는 수정이 아니다.

## 검증

새 `consentSnapshot.test.ts`의 집중 검사 19개가 모두 통과했다. 외부 hook의 쓰기를 모사해 prepare → 질문 전 → 응답 기록 → apply 사이의 무시 파일 변경에도 기존 저장소의 준비 커밋까지 완료하고, 기존 hook 설정과 중복 적용 방지를 유지하는지 확인했다.

필수 설정·문서, 사용자 지정 문서·템플릿·spec, 무시된 준비 README, 추적 파일·새 파일·자체 단계 로그는 계속 보호한다. 경로 추가·삭제, Git 상태별 오류, 출력 개수 제한, 이전 기록 호환, Git 없는 디렉토리와 worktree, 도움말 허용/명령 연결 차단도 검사했다.

최종 코드의 `npm test` 단일 전체 실행은 **759개 중 755개 통과·실패 0개·생략 4개**다. 생략은 Windows의 파일명 대소문자 2개와 POSIX 권한 2개다. 새 집중 검사 19개는 전체 실행에 포함되므로 합산하지 않는다. 기존 동의·Codex·플러그인·업데이트·기능 추가/fix/refactor 전체 흐름도 이 회귀 범위에 포함된다. 명령·로그 해시·검증 한계는 [증거 JSON](evidence/consent-snapshot-2026-10-06.json)에 기록했다.

Git·파일 시스템·커밋은 실제로 실행했다. 질문 이벤트·사용자 선택과 외부 hook 파일 쓰기는 자동 fixture이며 실제 Claude Code 화면이나 AI-DLC 엔진을 실행한 검증은 아니다. 대형 저장소의 속도 개선은 측정하지 않았다.

## 문서와 설치 반영

README·사용·설치·설계·요구사항·ca-answer 참고 문서와 이력 인덱스를 갱신했다. 앞선 이력과 수치는 해당 실행의 기록으로 보존한다. 기존 CLI도 갱신해야 하며 템플릿만 바꿔서는 수정이 적용되지 않는다. 호스트를 다시 연 뒤 동의를 새로 준비한다. 사용자 저장소의 외부 hook 설정이나 전역 설치본은 이번 코드 수정에서 직접 변경하지 않았다.
