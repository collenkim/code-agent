# 단계별 사용자 선택 점검

미응답 준비 기준을 선택지 없이 특정 문구로 답하도록 요구하는 문제를 보완했다. 17개 진입 절차와 준비·접수·전체 개발 단계에서 질문 조건, 선택 후보, 답 후 진행을 정의했다.

## 점검과 수정

| 범위 | 확인된 빈틈·구분 | 반영 |
|---|---|---|
| 준비·도입 | 기본안 확인의 구체적 선택 형태와 두 기준의 분리가 불명확 | ca-docs 3에 테스트·품질 각각 제안 기준 사용·항목 수정·보류, 내용·근거 제시, 도구 호출, 문서 동의 분리 |
| 접수·같은 ID 재접수 | 준비로 연결하는 문장은 있지만 초안 저장 후 미응답을 재제시하는 행동이 구체적이지 않음 | ca-request에 기존 답 보존·미응답 선택지를 같은 턴에 도구로 재개 |
| 분석·영향·설계·계획 | 일반 질문과 계획 승인·지적 판단을 구별해야 함 | 기준·범위·호환성·권한 결정의 후보와 답 후 담당 연결, plan 동의 전 예비 승인 질문 금지 |
| 구현·check·test | 한도·재현·환경·범위 변경의 선택이 실제 허용된 동작이어야 함 | 범위 내 해결·재계획·보류와 실제 가능한 judgment/repro-log만 연결, 러너 재선택·검증 생략 금지 |
| review·integrate·deliver | 지적 수정·사람 판단·반영 승인이 서로 다름 | 단계별 선택 후보와 별도 동의 연결, deliver의 항목 선택·최종 승인 형식 유지 |
| 재개·조회·사전 판별 | 상태 조회를 개발 요청으로 확대하거나 원인 판단을 사용자에게 넘기면 안 됨 | 단순 조회 유지, 중복·기존 답 재질문 금지, 근거·Jira 정보 요청과 원인 판별 분리 |

선택 표는 ca-answer/reference.md에 두고 17개 진입과 두 호스트 ca-answer에서 질문·대기 시 참조한다. 표는 매 단계 강제 질문 목록이 아니다. 이미 정해진 일·허용된 조회·정상 진행은 계속한다. 일반 질문 도구와 동의 관찰·적용 규칙은 분리한다. 기존 승인·단계 이동 게이트는 유지했다.

Stop에는 준비·접수·전체 단계 공통으로 마지막 응답의 선택지 없는 특정 문구 입력 요구를 한 번 교정하는 보조 검사를 추가했다. 인용 로그·코드·동의 안내 줄을 제외하며 반복 차단하지 않는다. 실제 질문을 이미 호출했다면 반복하지 말고 기존 선택지를 안내하도록 한다. 의미 전체를 해석하는 검사가 아니며, 목록 항목 둘 이상이 있다는 사실만으로 적절한 후보나 실제 UI를 보장하지 않는다. 이벤트가 마지막 응답을 제공하지 않으면 이 검사는 실행할 수 없다.

## 검증 범위와 한계

회귀 시험은 두 호스트 생성본의 전체 PHASES 행, 준비·접수·재개 명령 포함, 모든 진입의 선택 표 참조, UZRF-392와 같은 재접수에서 미응답 기준을 독립 질문으로 연결하는 지침 계약을 대조한다. 실행 시험은 준비·접수·전체 PHASES에서 두 호스트의 Stop 판정을 대조한다. cloud 설치본의 최신 여부와 실제 화면에서 선택·응답·재개까지의 동작은 별도 확인이 필요하다.

`scripts/evaluate-question-choices.cjs claude|codex`는 생성 지침과 합성 재접수 상황을 실제 CLI 모델에 제공한다. 임시 git 저장소에서 실행하며 사용자 동의·접수 기록을 만들지 않는다. Codex는 두 독립 질문의 `request_user_input_async` 호출과 동일 call_id의 `accepted: true`를 확인한다. CLI 요약은 질문을 일반 메시지로 표시할 수 있어 실제 호출 기록을 함께 검사한다. Claude는 질문 도구를 제외한 비대화형 실행에서 사유와 두 질문의 번호 선택지를 검사한다.

## 예산

단계별 표는 필요할 때 읽는 reference에 모았다. reference 7,400→9,600자, Claude ca-answer 8,400→8,700자, ca-docs 6,600→6,900자, Codex ca-answer 4,900→5,100자, 흐름 합계 Claude 52,500→53,200자·Codex 53,000→53,400자로 조정했다. 도구 호출과 단순 출력의 구분·대체 안내를 각 호스트 진입에 명시하는 비용을 포함한다. 다른 예산은 유지했다.
