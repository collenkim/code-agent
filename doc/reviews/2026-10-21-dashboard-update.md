# 대시보드 확인 업데이트

구현 커밋: `e193ad2`.

## 변경 범위

프로젝트 없이 릴리스를 설치하는 경로와 프로젝트별로 설치된 릴리스를 적용하는 화면 확인 경로를 추가했다.

- `update --install-only --preview --json`은 기존 소스 미리보기의 로컬 검사·문구를 공유하되 프로젝트 정보 없이 `lines`·`shownHash`를 반환한다. 확인 실행은 `--shown-hash <해시> --json`이며 `installGitRelease` 결과를 `{id, commit, created, log}`로 반환한다.
- `update --release <ID> --preview --json`은 현재 버전·대상 릴리스·상태 세대와 문구를 묶는다. 확인 실행은 기존 `runReleaseApply(trigger: release)`를 사용하므로 작업 중이면 예약하고 종료 코드 3을 반환한다.
- 호스트 표지는 `policy-forbids`, 해시 불일치는 `stale-state`로 확인 기록·fetch·적용보다 먼저 거부한다. 모델의 소스 업데이트 차단 깃발에도 세 가지 새 깃발을 추가했다.
- PC 저장소의 `update-confirmations.jsonl`에 PC 신뢰와 같은 `createdBy: {actor, channel, shownHash}`를 기록한다. `tty`와 `dashboard`를 구분하며 확인 뒤 실행 전에 기록한다.
- README·설치·사용법·흐름도를 현재 계약에 맞추고, 업데이트 절의 과거 릴리스 저장소 이행 경위는 제거했다. 최종 검토와 근거는 이 기록과 JSON으로 모았다.

## 설계 판단

설치 전용 경로는 프로젝트 설치 여부 검사보다 먼저 분기한다. 미리보기에서는 fetch·잠금·확인 기록을 만들지 않는다. 해시는 소스 경로·브랜치·HEAD·upstream 설정·릴리스 저장소와 표시 문구를 묶으며, 원격 주소의 자격 정보는 출력하지 않는다. 원격의 최신 커밋은 확인 후 fetch할 때 결정한다.

프로젝트 적용 해시는 프로젝트 경로·현재 runtime 기록·대상 릴리스 정보·적용 옵션·표시 문구를 묶는다. 실제 작업 중 여부와 상태 세대 검사는 기존 적용 실행기가 처리한다. 설치·위임 규약과 프로젝트 승인·증거·작업 상태 형식은 바꾸지 않아 `STATE_SCHEMA`를 유지한다. 기존 동의용 소스 스냅샷의 직렬화 순서도 유지한다.

확인 기록은 성공 증거가 아니다. 실행 중 실패해도 유효하게 받은 확인은 남는다. 이름은 OS 사용자의 표시 이름이며, 화면 해시와 호스트 표지는 같은 OS 계정에서 호출할 수 있는 프로세스에 대한 신원 증명이 아니다. 대시보드가 문구를 표시하고 사용자의 확인을 받은 뒤 호출하는 계약이다.

## 검증

Windows·Node 24.19.0에서 `npm run build`와 집중 회귀를 통과했다. 8개 시험 파일의 137개 중 136개 통과, 실패 0개, 플랫폼 조건 생략 1개이며 약 434초 걸렸다. 최종 명령·로그 해시와 확인 범위는 [근거 JSON](evidence/2026-10-21-dashboard-update.json)에 기록했다. `help update`의 새 사용법과 `git diff --check`도 확인했다.

- 임시 Git 원격·소스와 격리 릴리스/PC 저장소에서 읽기 전용 미리보기, 확인한 설치, 같은 커밋 재사용, upstream·브랜치·저장소 변경과 호스트 표지 거부를 확인했다.
- 실제 CLI와 격리 A/B 릴리스로 JSON 한 줄, 프로젝트 없는 미리보기, 잘못된 인자 거부, 적용 전후 해시 결속, 적용과 작업 중 예약을 확인했다. 미리보기·거부 전후 프로젝트 전체 파일의 경로·내용 해시를 대조했다.
- 터미널 확인 어댑터로 `tty` 기록과 확인 중 상태 변경 거부를 확인했다. hook 차단과 문서 동기화·hook 로드·기존 동의 결속/출력 회귀도 통과했다.

## 확인하지 않은 범위

실제 브라우저 화면·대시보드 클릭과 실제 TTY 입력은 이번 시험 범위가 아니다. 사용자의 릴리스 저장소와 네 서비스 프로젝트에는 설치·적용하지 않았다. 전체 회귀 대신 변경 경로와 기존 동의의 집중 회귀를 수행했다.
