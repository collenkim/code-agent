description: 프로젝트 필수 문서(아키텍처·코드 컨벤션)를 점검하고, 없으면 작성으로 안내한다.
---

> 역공학·사용자 입력으로 문서를 **작성**하는 절차는 P2 에서 들어온다. 지금은 점검과 안내만 한다.

1. Bash: `code-agent status` 의 "프로젝트 문서" 를 보여 준다.
2. ✗ 인 문서가 있으면 무엇이 필요한지 알려 준다:
   - **아키텍처**: 기술 스택 · 모듈/패키지 구조 · 계층과 책임 · 의존 방향 · 공통 모듈 · 주요 결정.
     `code-agent.json` 의 `docs.architecture` 에 경로를 등록한다.
   - **코드 컨벤션**: 명명 · 계층별 규칙 · 예외 처리 · 테스트 규칙. `code-agent.json` 의 `conventions` 에 경로를 등록한다.
3. 사용자가 원하면 사용자와 대화로 문서 초안을 함께 쓴다. 코드로 확인되지 않는 것은 지어내지 않고 묻는다.
