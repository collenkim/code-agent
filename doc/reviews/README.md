# 최신 검증

현재 동작은 [프로세스 흐름도](../process-flow.md), [사용 안내](../usage.md), [설계](../design.md)를 기준으로 읽는다.

| 검증 | 범위 |
|---|---|
| [호스트 흐름·최신 자동 시험](2026-11-03-host-flow-validation.md) | 동의 전문·평가·실행 권한·TC·Codex 후속·접수 표식, 실행 조건·템플릿 예산·미확인 범위 |
| [보존한 호스트 측정](2026-11-01-validation.md) | 이전 버전에서 실제 측정한 범위와 한계. 원본 집계·재현 기준선 연결. 새 코드 재검증이 아님 |

자동 회귀와 실제 모델·사람 검증을 구분한다. 현재 결과·실행 조건·생략·미확인 범위와 필요한 원본 근거만 유지한다. 완료된 지시·중복 집계·변경 경위는 Git 이력으로 확인한다. 재생성 가능한 실행 로그는 커밋하지 않는다.
