현재 동작은 [프로세스 흐름도](../process-flow.md), [사용 가이드](../usage.md), [설계](../design.md)를 기준으로 읽는다. 검증 기록은 아래의 대상·실행 조건에 한정해 읽는다.

| 검증 | 범위 |
|---|---|

자동 회귀와 실제 모델·사람 검증을 구분한다. 현재 결과·실행 조건·생략·미확인 범위와 필요한 원본 근거만 유지한다. 비공개 증거는 종류와 대조 범위만 적고, 사용자 이름·세션 식별자가 포함된 로컬 절대 경로나 임시 디렉터리 이름을 공개 문서에 싣지 않는다. 저장소에 포함되지 않은 증거는 공개 문서만으로 재현할 수 없음을 명시한다. 완료된 지시·중복 집계·변경 경위는 Git 이력으로 확인한다. 재생성 가능한 실행 로그는 커밋하지 않는다.

실행 보고서의 기본 위치는 Git 무시 경로 `.code-agent/evaluations/`다. `evaluate-*`의 실행·재개·재검사와 `summarize-evaluations.cjs`가 같은 경로를 쓴다. 별도 보관은 `CODE_AGENT_EVAL_REPORT_DIR`에 절대 경로를 지정한다. 기존 공개 `evidence/` 파일은 덮어쓰지 않으며, 이전 보고서를 재개하려면 선택한 보고서 디렉터리에 사본을 둔다. 원시 보고서에는 로컬 경로·대화가 포함될 수 있으므로 공개 검증 문서는 검토한 요약만 갱신한다.
