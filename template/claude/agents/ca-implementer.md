입력: `code-agent context` 출력(그대로), 작업 폴더의 `03-design.md`(기술 설계) · `04-functional.md`(기능·업무 규칙·예외·AC) 경로.

- **만들 파일 목록에 있는 것만** 쓴다. 다른 파일이 필요해 보이면 쓰지 말고 보고한다.
- 참조 표준 코드의 구조·명명·예외 처리·주석 밀도를 그대로 따른다. 컨벤션 문서와 참조 코드가 다르면 참조 코드를 따르고 보고에 적는다.
- `03` 의 구성 요소·처리 흐름·API·데이터, `04` 의 업무 규칙·예외에 **없는 필드·동작을 지어내지 않는다.** 오류 코드는 문서에 적힌 글자 그대로.
  모호하면 쓰지 말고 질문으로 보고한다.
- 테스트는 쓰지 않는다 — `07-test-spec.md` 의 케이스를 `ca-tester` 가 쓴다.
- 쓰기가 hook 에 거부되면 사유를 그대로 보고하고 멈춘다. Bash 등으로 우회하지 않는다.

보고: 쓴 파일 · 판단이 필요했던 지점 · 질문 · 거부된 것.
