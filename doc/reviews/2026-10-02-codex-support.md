# Codex 지원 변경·검증 이력

기준일: 2026-10-02. 현재 사용법은 [Codex 연동](../codex.md)을 따른다. 이 문서는 도입 당시 변경과 검증 근거를 기록한다.

## 요구와 적용

Claude에서 사용하던 단계별 노드·계획 서브 에이전트 구조를 Codex에서도 실행하고, 기존 Claude 프로젝트를 보존한다. 새로운 모델 API나 상주 서버를 추가하지 않고 호스트 어댑터로 구현했다.

- `init`·`update`·`doctor`에 `--host claude|codex|both`를 추가했다. 설치 이력을 기록해 이후 갱신·점검 대상과 개발용 CLI 경로를 유지한다.
- 공통 업무 지침에서 Codex 스킬 18개와 TOML 역할 8개를 생성한다. 승인 스킬은 별도 계약으로 제공하며 Claude 도구·경로·인자 표기를 그대로 복사하지 않는다.
- Codex 훅 5종을 `codex-event`로 받아 패치, 사용자 메시지, 계획·리뷰 실행, 턴 종료를 기존 판정 코드에 연결한다. Codex transcript 파일은 실행 근거로 파싱하지 않는다.
- 승인 대상 해시와 세션·호출 식별자는 기존 동의 검증을 공유한다. Codex의 승인 출처 `codex-prompt`를 원장에 남기며 일반 대화·도구 응답을 승인으로 추측하지 않는다.
- 패치의 이동 전후와 모든 파일을 검사한다. 호스트 설정 직접 변경과 모델의 관찰 명령 호출을 거부한다. 조사 범위와 준비 파일의 기준 커밋에 Codex 경로를 반영했다.
- 단계 안내 문구를 특정 호스트에 묶지 않도록 바꿨다. Codex 모델·추론 강도 상속과 Claude 전용 토큰 집계의 범위를 명확히 했다.

## 검증과 수정 이력

전체 회귀 695개: 통과 690, 실패 1, 생략 4. 실패한 안내 문구 기대값을 수정한 뒤 동일 사례가 통과했다. 최종 설치·호스트 검사 68개도 모두 통과했다. 중복을 제외한 최종 검증 범위는 695개 중 691개 통과·실패 0·생략 4개다. 전체 회귀 전체를 최종 수정 뒤 다시 실행한 수치와는 구분한다.

최초 Codex 집중 검사 15개 중 13개가 통과하고 2개가 실패했다. 하나는 작업이 없을 때 `codex-event` 직접 호출을 막는 분기가 빠져 있었고, 다른 하나는 최초 기준 커밋 대상에 Codex 설치 파일이 없어 검증에서 계획 밖 변경으로 판정된 문제였다. 두 경로를 수정한 뒤 같은 검사 15개가 모두 통과했다. 실패 기록을 성공 결과로 덮어 해석하지 않는다.

전체 회귀 및 최종 보완 검사의 정확한 실행 수·성공·실패·생략·시간·로그 해시는 [원자료 요약](evidence/codex-support-2026-10-02.json)에 기록한다. 과거 계획·검증 노드 보고서의 수치와 합산하지 않는다.

검사 범위에는 단독·양쪽 설치, 반복 갱신, 사용자 설정과 같은 그룹의 다른 훅 보존, 잘못된 설정 거부, doctor의 역할 누락·matcher 검사, 패치 경로 검사, 미승인 적용 거부, 사용자 응답 재사용 거부, 대상 변경·서브 에이전트·누락된 세션·추가 문구 거부, 보류 처리, 입력 변경 시 계획 결과 거부가 포함된다. 임시 Git 저장소에서 Codex 이벤트로 접수·분석·설계·계획·승인·Task·검증·리뷰·통합도 진행했다.

실제 CLI 하위 프로세스의 JSON 응답과 오류 종료 코드도 확인했다. 호스트의 시작·완료 및 사용자 응답 이벤트는 테스트에서 합성한 자료이며 실제 모델이나 사람의 판단 품질을 측정한 결과가 아니다.

## 확인한 환경과 한계

- 로컬 `codex-cli 0.159.3`의 버전과 `hooks`, `multi_agent` 활성 상태를 조회했다. 최소 지원 버전이나 모든 Codex 클라이언트의 동일 동작을 보증하는 수치는 아니다.
- 설치 파일은 테스트용 프로젝트에서 생성·검사했다. 실제 Codex UI에서 프로젝트 훅을 신뢰하고 유료 모델을 호출하는 실사용 측정은 수행하지 않았다.
- 훅 파일이 존재해도 신뢰되지 않거나 호스트가 해당 이벤트를 지원하지 않으면 실행되지 않는다. doctor는 이를 실제 실행 성공으로 표시하지 않는다.
- Codex 사용량 집계는 추가하지 않았다. 모델·추론 강도는 부모 설정을 상속한다. 문서의 지원 범위를 넘어 결과를 주장하지 않는다.

## 문서 정리
