# 외부 계약 인계와 계획 응답 검증 최종 정리

기준 소스는 `2552d3a`이며 시작 시 미커밋 변경은 없었다. master-agent의 `docs/implementation.md` 작업 지시와 `2026-10-16-full-flow.json`·`2026-10-16-answer-context.json`을 근거로 code-agent만 수정했다. 상위 저장소와 기존 실행 증거는 수정하지 않았다.

## 최종 동작

| 대상 | 결과 |
|---|---|
| 외부 의존 계약 | `planning contracts`가 지정 Git 파일의 경로·커밋·현재 바이트·해시·원문 항목을 대조하고 사본을 모든 계획 담당에게 전달한다. 원본·사본 변경은 입력 해시와 계획 승인에 반영한다. 저장소 전체 읽기 권한을 열지 않는다. |
| 답 출처 | `planning reuse-answer`가 원문을 질문·답·근거 묶음과 결속하고 `contract`로 표시한다. Source 문자열·옛 관찰 기록으로 인증하지 않으며 실제 관찰·master 위임·사람 전달 답과 구분한다. |
| 결과 응답 | 단일 결과 포인터 앞뒤의 설명을 허용하면서 배정 소유권·스키마·입력 해시·크기 검사를 유지한다. 리뷰는 지적과 검토 위치를 `{findings, checked}`로 분리하고 없음과 실제 지적의 상충을 거부한다. |
| 계획·테스트 | 생성 지침과 제출 전 점검에 Task의 R → AC → TC 연결을 명시한다. AC 없는 TC와 명백한 전체 테스트 통과 자기참조 항목을 사전 거부하며 기존 제출·독립 검토·승인 게이트를 유지한다. |

상태 형식 세대는 4다. 기존 계약을 사용하지 않는 작업의 입력·승인 해시와 기존 답 출처는 유지한다. CLI·상태 규격은 [계약 인계](../dependency-contracts.md), 전체 절차는 [프로세스 흐름도](../process-flow.md)를 따른다.

## 최종 검증

최종 전체 시험은 1595개 중 1591개 통과, 실패 0개, 플랫폼 조건 생략 4개다. 마지막 안내 문구 정리 후 빌드와 답 출처·호스트 표기·hook import·템플릿 예산·문서 동기화 시험 47개도 모두 통과했다. 실행 조건은 [검증 자료](evidence/2026-10-16-dependency-contracts.json)에 기록했다. 임시 Git 저장소와 담당 응답 fixture로 다음을 확인했다.

- 정상 계약의 explore·design 전달과 사본 근거 수용, 원본 변경에 따른 완료 결과·계획 승인 해시 변경
- 잘못된 경로·커밋·해시·원문·상충 키·과대 입력 거부, 실행 중 등록 거부
- 계약 답의 질문·답·Source·원본·사본·원장 변조 거부, 미확인 질문 유지, pending·deferred 처리, 이후 실제 관찰·위임·사람 전달 출처의 구분
- 단일 포인터와 설명의 첫 완료, 잘못된 경로·복수 포인터·손상 JSON·스키마·소유권·입력 해시·크기 초과 거부
- 구조화 리뷰의 한 번 완료와 리뷰 게이트 통과, 없음과 실제 지적의 상충·자유 설명·추가 키·JSON 문자열 내부 주석을 통한 지적 은닉 거부
- 실행 가능한 TC 수용, AC 없는 TC·자기참조 TC·T2 담당 요구의 AC 누락 거부

프로세스 종료·생존 확인은 Windows 샌드박스 권한의 영향을 받아 최종 전체 시험은 샌드박스 밖에서 실행했다. 게이트나 실패 시험을 삭제·완화하지 않았다.

## 확인하지 않은 범위와 상위 작업

실제 Claude·Codex 모델로 두 프로젝트를 다시 실행하거나 재질문·재호출·토큰 감소량을 측정하지 않았다. 담당 결과와 사람 관찰 기록은 회귀 시험의 fixture다. 자연어 요구와 계약 사이의 의미상 모순은 담당·독립 검토와 사람 판단 대상이며 같은 키 충돌 검사로 완전히 판정할 수 없다.

master는 선행 산출물의 커밋된 계약 문서와 일관된 항목 키를 선정하고 계약 JSON을 개발 호스트에게 전달해야 한다. 호스트는 첫 세부 배정 전에 등록한다. 대화의 criteria만으로 원문 재인용을 인증하지 않는다. 기존 master v1 위임·사람 전달 계약은 유지한다. 병렬 스케줄링·실행 상태 UI·실제 모델 재검증은 상위 작업이며 이 변경에 포함하지 않는다.

## 템플릿 예산

필수 출처 안내와 구조화 리뷰 규격을 담당이 호출 때 읽도록 하기 위해 reviewer 3700자, Claude 답 지침 9100자, Codex 답 지침 5400자, 계획 기준 3100자로 예산을 맞췄다. `template-sizes --suggest`의 여유율을 따라 Claude 흐름 예산은 53300자이며 실제 합계는 52225자다. Codex 흐름 실제 합계는 48454자이며 기존 합계 예산 안이다. 중간 실행 로그 대신 최종 검증 자료 하나만 보관한다.
